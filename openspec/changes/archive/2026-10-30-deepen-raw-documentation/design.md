# Design

Expand existing independent knowledge topics using revision-pinned raw sources and code observations. Maintain a requirements inventory with explicit source links, draft status, code evidence and unresolved discrepancies. A section index identifies coverage still needing claim-level review; it is not a certification that each section is complete. Add selected verifiable behavior to the existing draft baseline without turning unresolved questions into requirements.

Graphify is optional derived discovery. Its existing repository skill documents installation and use; generated output stays local. The initial whole-repository scan exceeded the skill's threshold; corpus selection and graph generation are tracked in `complete-source-coverage`. No public API, implementation or production dependency changes. A new ADR is unnecessary for this documentation review.
